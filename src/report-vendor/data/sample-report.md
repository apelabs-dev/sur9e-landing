## STAR stories

#### The knowledge base that ended Slack noise

> The partner support team was losing **hours every week** digging through Confluence for answers. I designed and built a RAG pipeline on Pinecone — chunked the documentation, benchmarked the embedding model, and wired the retrieval layer to a Slack bot the team actually used. When the wrong context came back on edge-case queries, I traced it to chunk overlap and fixed the splitting strategy. **Information-finding time dropped 60%**; partners got accurate answers instead of "let me check and get back to you."

*Reflection: I'd have built an eval harness with labeled queries at the start instead of debugging by feel. I build that step in now before tuning any retrieval system.*

#### Agentic onboarding pipeline that ran itself

> Partner onboarding was fully manual — 12+ partners, each requiring credential setup, doc delivery, and follow-up coordination over email. I built an n8n workflow using OpenAI Assistants API to automate each handoff: credential provisioning, doc delivery triggers, and failure-state routing. When a step errored, the workflow caught it and either retried or escalated. **Manual touchpoints dropped ~60%**; the team stopped babysitting the process.

*Reflection: We ran blind for two weeks before I realized some partners were stalling at credential setup. I'd add a monitoring dashboard in week one next time.*

#### AI remarketing that recovered stalled applications

> Stalled loan applications were leaking revenue with no systematic follow-up. I built a pipeline that identified high-intent drop-offs, personalized SMS outreach using OpenAI, and triggered sends at the right point in the decay curve. Output validation was the hard part — early runs produced technically correct messages that read wrong in context, so I added a classification step before any message sent. **Recovered 12% of stalled applications**; response rate ran **3× industry benchmark**.

*Reflection: The classification guardrail was the right call, but I should have designed it into the architecture before the first deploy, not retrofitted it after the first bad batch.*
