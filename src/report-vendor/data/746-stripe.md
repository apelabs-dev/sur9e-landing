## STAR stories

#### The Stripe Connect architecture

> We needed to launch a payments marketplace — multiple merchants, split routing, compliance workflows — with no prior Stripe Connect implementation in the codebase and a hard deadline. I owned the full architecture: designed the connected-account structure, built the split-payment routing logic in Python, handled onboarding flows across **12+ merchants**, and documented the integration for the partner-facing API. The platform went live and processes real transactions today.

_Reflection: I'd scope a sandbox-to-prod migration checklist earlier. I build that step in now for every new integration._

#### The enterprise integration that ran 60% faster

> A key enterprise partner was onboarding manually — every new system required a week of back-and-forth on custom setup. I designed the External Partner API (OAuth 2.0 + AWS ECS), wrote the documentation, and ran onboarding for the first four partners myself. Time-to-integrate dropped **40%**, and the workflow I built handled subsequent partners without me in the loop.

_Reflection: I underestimated how much partners copy-paste from sample requests — I now write more example-first docs and fewer conceptual ones._

#### The production AI system that changed the support queue

> Support tickets were climbing because reps couldn't find policy answers fast enough. I scoped, built, and deployed an internal knowledge base on Pinecone + GPT-4 — semantic search across company docs, context-aware responses, integrated into the existing tools. The team started using it on day one. Info-retrieval time fell **~60%** and the support workload shifted toward edge cases the AI couldn't handle, which is where humans should be.

_Reflection: Embedding quality mattered more than I expected — I now do a retrieval-accuracy audit before any RAG launch, not after._
